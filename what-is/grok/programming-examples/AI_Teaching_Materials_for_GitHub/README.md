# AI Teaching Materials for Children (Ages 8–14)

Ready-to-use guides and programming examples for teaching Artificial Intelligence.

## Guides (Markdown)

| File | Description |
|------|-------------|
| [AI_Teaching_Guide_for_Children.md](AI_Teaching_Guide_for_Children.md) | Complete course: history → Predictive ML → Generative AI → Agentic AI → Robots → AGI + ethics + 4-session plan |
| [Neural_Networks_Visual_Exploration.md](Neural_Networks_Visual_Exploration.md) | Visual, slide-style explanation of neural networks |
| [Backpropagation.md](Backpropagation.md) | Simple explanation of how networks learn by going backward |

## Programming Examples

See the [`programming-examples/`](programming-examples/) folder:

- `01-predictive-ml/` – simple rule-based predictor
- `02-generative-ai/` – tiny sentence generator
- `03-agentic-chatbot/` – rule-based chatbot
- `04-robots/` – 1-D robot path simulation
- `05-neural-networks/` – conceptual notes
- `06-backpropagation/` – simple learning loop

All Python scripts run with plain Python 3 (no extra libraries).

## How to use on GitHub

1. Copy this entire folder into your repository.
2. The Markdown files render nicely on GitHub.
3. Children / students can open the `.py` files in Thonny, VS Code, or any Python environment.

**Safety reminder:** Always supervise children when they use online AI tools.
