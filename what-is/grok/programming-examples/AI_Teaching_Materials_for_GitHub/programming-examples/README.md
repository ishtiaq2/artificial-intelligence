# Programming Examples

Supporting code for the AI Teaching Guide for Children.

| Folder | Topic | Files |
|--------|-------|-------|
| `01-predictive-ml/` | Predictive AI & Machine Learning | `simple_predictor.py` |
| `02-generative-ai/` | Generative AI | `sentence_generator.py` |
| `03-agentic-chatbot/` | Chatbots & Agents | `simple_chatbot.py` |
| `04-robots/` | Robots | `robot_path.py` |
| `05-neural-networks/` | Neural Networks | (conceptual + unplugged) |
| `06-backpropagation/` | Backpropagation | `simple_learning_loop.py` |

All Python examples run with a standard Python 3 installation (no extra packages required).

See the main Markdown guides in the parent folder for full explanations and classroom activities.
