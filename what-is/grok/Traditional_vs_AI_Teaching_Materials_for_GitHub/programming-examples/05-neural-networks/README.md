# 05 – Neural Networks (Code Exploration)

Simple educational Python examples that match the visual guide.

| File | What it shows |
|------|---------------|
| `01_single_neuron.py` | One neuron: inputs × weights → activation |
| `02_tiny_network_forward.py` | Small network (2→3→1) doing a forward pass only |
| `03_learn_with_backprop.py` | Tiny network that actually **learns** using backpropagation (needs NumPy) |

## How to run

```bash
python 01_single_neuron.py
python 02_tiny_network_forward.py
python 03_learn_with_backprop.py
```

All files are heavily commented for teachers and older students (≈10–14).
