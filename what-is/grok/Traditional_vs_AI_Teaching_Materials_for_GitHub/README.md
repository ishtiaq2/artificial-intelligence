# AI Teaching Materials for Children (Ages 8–14)

Ready-to-use guides and programming examples for teaching Artificial Intelligence.

## Important: Traditional Programming vs AI Programming

See **[Traditional_vs_AI_Programming.md](Traditional_vs_AI_Programming.md)** for a clear explanation of why most of the early examples look like normal if-else programming, and how real AI code is different (it **learns patterns from data** instead of following hand-written rules).

## Programming Examples

| Folder | Style | What it shows |
|--------|-------|---------------|
| `01-predictive-ml/` … `04-robots/` | Traditional (rules) | Easy starting point – human writes the logic |
| `05-neural-networks/` | Transition | Single neuron → forward pass → simple learning |
| `06-backpropagation/` | Learning idea | Adjusting a number based on error |
| **`07-ai-style-learning/`** | **AI style** | **Computer finds the pattern from examples** |

### Recommended order for the code examples

1. Start with the rule-based ones (so children understand “making a decision”).
2. Read `Traditional_vs_AI_Programming.md`.
3. Run the examples in `07-ai-style-learning/` to see the difference.
4. Then explore the neural-network files in `05-neural-networks/`.
