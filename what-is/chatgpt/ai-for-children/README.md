# AI for Children: From Rules to the Future

A hands-on, child-friendly Artificial Intelligence course and GitHub-ready repository.

## The learning journey

**Rules → Learning → Neural Networks → Creating → Reasoning → Acting → The Future**

Each lesson contains a small, runnable Python example.

## Recommended age

- **7–10:** Learn with an adult, read the explanations, and change the values in the examples.
- **10–14:** Run and modify the Python programs.
- **14+:** Extend the projects and explore the optional machine-learning packages.

## Quick start

```bash
git clone <YOUR-GITHUB-REPOSITORY-URL>
cd ai-for-children
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

Run the first lesson:

```bash
python lessons/01_rules/weather_rules.py
```

## Teaching principle

AI is not magic.

Modern AI is built from:

**mathematics + data + algorithms + programming + computers**

The course teaches children to ask:

1. What problem am I solving?
2. What information does the AI need?
3. How does the AI make a decision?
4. How can the AI be wrong?
5. How can humans keep the system safe?
