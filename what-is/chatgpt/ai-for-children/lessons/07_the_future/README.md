# Lesson 7: The Future

## Questions for discussion

- Can AI become more general?
- Should AI control robots?
- How should humans check AI decisions?
- What jobs might change?
- What new jobs might appear?
- What is AGI?

AGI means Artificial General Intelligence.

It is generally used to describe the idea of AI with broad, flexible abilities across many tasks. There is still significant debate about the definition and how it should be measured.
