# How to Publish This Project on GitHub

## 1. Create an empty repository

On GitHub:

1. Click **New repository**.
2. Choose the name `ai-for-children`.
3. Select **Public** or **Private**.
4. Do not initialize it with a README if you are uploading this complete project.
5. Create the repository.

## 2. Push this directory

From the project directory:

```bash
git init
git add .
git commit -m "Initial AI for Children course"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/ai-for-children.git
git push -u origin main
```

## 3. Future updates

```bash
git add .
git commit -m "Add lesson improvements"
git push
```
