# Teaching Guide: AI for Children

## Course format

Each lesson follows this pattern:

1. **Ask a question**
2. **Explain with a real-world example**
3. **Run a small program**
4. **Change one value**
5. **Observe what happens**
6. **Discuss why**

## Suggested eight-week course

### Week 1: What is AI?

**Goal:** Understand that AI performs tasks using rules, learned patterns, or trained models.

Activity: Ask children to classify familiar technology as:

- normal program
- AI
- robot
- both AI and robot

### Week 2: Rules

Run `lessons/01_rules/weather_rules.py`.

Challenge: Add a rule for snow.

### Week 3: Learning

Run `lessons/02_learning/study_predictor.py`.

Explain:

- training data
- features
- labels
- model
- prediction

Challenge: Change the training examples.

### Week 4: Neural Networks

Run `lessons/03_neural_networks/simple_neuron.py`.

Explain the equation:

`output = weight × input + bias`

Challenge: Change the weight.

### Week 5: Creating

Run `lessons/04_creating/story_generator.py`.

Explain that the program creates combinations. Then explain that modern generative AI uses much more advanced learned models.

### Week 6: Reasoning

Run `lessons/05_reasoning/route_reasoner.py`.

Explain that the program compares options and chooses a solution according to a goal.

### Week 7: Acting

Run `lessons/06_acting/tool_agent.py`.

Explain:

`goal → choose tool → act → inspect result`

### Week 8: The Future

Discuss:

- robots
- multimodal AI
- AI safety
- AGI
- jobs and creativity

Finish with the capstone project.

## Teaching advice

Do not start with difficult terminology.

Start with:

> "What problem should our computer solve?"

Then gradually introduce the AI vocabulary.

## Important vocabulary

| Word | Child-friendly meaning |
|---|---|
| Data | Information |
| Algorithm | A method or recipe for solving a problem |
| Model | A trained system that finds patterns |
| Training | Learning from examples |
| Prediction | An estimated answer |
| Neural network | Connected mathematical units that learn patterns |
| Generative AI | AI that creates new content |
| AI agent | AI that can choose and use tools to achieve a goal |
