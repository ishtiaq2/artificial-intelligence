# AI Safety and Parent Guide

Children should learn that AI can be useful but can also make mistakes.

## Important rules

1. Do not share passwords.
2. Do not share private personal information.
3. Do not trust every AI answer automatically.
4. Ask an adult before following advice involving health, money, safety, or dangerous activities.
5. Remember that AI-generated pictures, voices, and videos can be fake.
6. Be respectful when using AI.

## Teaching question

Ask:

> If an AI gives two different answers to the same question, how can we check which answer is correct?

Possible answers:

- use trusted sources
- ask a teacher
- test the information
- compare reliable references
